# U2Net Planner

This directory contains the experiment planner for U2Net within the nnUNet framework.

## Overview

The U2Net planner is responsible for configuring and preparing experiments using the U2Net architecture. It handles data preprocessing, experiment setup, and parameter selection tailored for U2Net.
